# Ranger Rumble Offline

**English** · [Français](README.fr.md)

A tool to keep playing *Ratchet & Clank: Ranger Rumble* after its servers close on May 1, 2027.
For Windows and macOS, in 6 languages: English, French, Spanish, German, Italian and Portuguese.

## iPhone and Android

- **The save copy is made on iPhone or iPad only.**
- **The offline game (the mod) is for Android only.**
- **A copy made on iPhone works on Android**: your iPhone progress goes on in the offline game, on
  an Android phone or tablet.

## What the tool does

1. **Copy the save** (iPhone and iPad only, before May 1, 2027): scan the QR code with the iPhone,
   then install the profile from the Settings. When the game starts, the tool keeps a copy of your
   save and of the game's data. On Android, there is nothing to copy: you start a new game.
2. **Install the game** (Android only): the tool builds a version of the game that works without a
   server (Android APK), from the official 1.10.4 game you provide, with your iPhone save or a new
   game. Then it installs it on the phone by cable (on Android, turn on "File transfer" in the USB
   settings).
3. **Edit a save**: change heroes, levels, weapons, costumes, medals, currencies, statistics...
   from a file, a copy or straight on the phone by cable.
4. **Updates**: the game updates straight from the tool, with a simple cable, without losing your
   progress. The offline game announces new versions itself, in its inbox.

Warning: deleting the game also deletes the save!

## New features and changes from the original game

The whole game works without a server: shop, missions, events, Ranger Road, friends.

**Heroes**

- 7 new heroes: Molly, Helen, Terry, Crumby, Chance, Flare and Nakari.
- Rivet added (she is a mod, not a character planned by the developers).
- Nakari costs 750 Raritanium.
- The Ranger Road was updated to include the new heroes.
- New orbs for each new hero, found in the shop or in Reebos. Once a hero is at max level, the
  game no longer offers them.

**Weapons**

- Weapons now come in 2 kinds: main weapons and gadgets.
- Every weapon and every gadget can now be equipped on every hero.
- Weapons and gadgets unlock on the Ranger Road.
- A new weapon: the Scorpion Flail.
- The home screen shows the hero's weapons again, as in older versions.
- Weapons and gadgets can be upgraded to level 10 again.

**Modes and events**

- Bolt Rush together and Bolt Rush alone are now available.
- A 16-player Battle Royale was added. It unlocks by turning on "Prototype maps and modes" in the
  game's settings.
- The Mrs. Zurkon and random weapon events, as the developers had planned them.

**Playing together**

- Friends on the same Wi-Fi show up in the friends list: invitations and squads of 3 players.
- You can play remotely with a squad code, up to 3 players.
- Squad battles work in every mode except Mob Rush.

**Shop and rewards**

- New plan offers in Qredits, Qredits exchanged for Raritanium.
- More Raritanium in the daily rewards (days 3 and 7).

**Other**

- An artbook in the game's menu: game pictures, concept art, map layouts.
- You can now choose between four difficulty levels (easy, normal, hard, ultra hard).
- A new language: Polish.
- The game now announces new versions in its inbox.

## Install

Download `Ratchet_Ranger_Rumble.zip` from the latest version (**Releases** tab), then unzip it.

- **Windows**: the first time, double-click `Lancer (Windows).bat`. It installs what is needed,
  then creates the "Launcher Ratchet Ranger Rumble" shortcut on the Desktop.
- **Mac**: open "Launcher Ratchet Ranger Rumble". If the Mac refuses: System Settings > Privacy &
  Security > Open Anyway.

**Installing Python 3.15 beforehand is recommended.**

The first installation takes a few minutes (Python is downloaded if missing). Everything is
explained step by step in `Read me.txt`.

You also need the official 1.10.4 game (`.xapk`, `.apkm` or a complete `.apk`), 5 GB free, and a
64-bit Android phone or tablet (Android 7.1 or newer).

## What the tool contains, and what it does not

**Each player provides their own official copy of the game (1.10.4)**, and the tool changes it on
their computer. Nothing is sent anywhere, apart from the question "is there a new version?" asked
to GitHub.
