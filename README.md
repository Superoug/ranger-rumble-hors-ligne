# Ranger Rumble hors ligne

Un outil pour garder *Ratchet & Clank: Ranger Rumble* jouable après la fermeture de ses serveurs
(1er mai 2027), sur Windows, macOS et Linux.

Il a quatre onglets :

1. **Copier la sauvegarde** : garde une copie de ta sauvegarde officielle (iPhone/iPad) et des
   données du jeu, tant que les serveurs sont ouverts.
2. **Fabriquer l'APK** : fabrique une version du jeu qui marche sans serveur pour Android, à
   partir du jeu officiel que tu fournis toi-même (versions 1.10.4 et 1.10.3, et 1.1.0 si tu
   l'as, pour l'écran d'origine de l'événement de Mme Zurkon).
3. **Éditer une sauvegarde** : héros, niveaux, armes, costumes, médailles, monnaies, parties
   jouées, gagnées, perdues... tout se modifie. Par fichier ou directement par le câble.
4. **Mises à jour** : met à jour l'outil, puis le jeu du téléphone par le câble, sans perdre
   la progression. Le jeu hors ligne annonce lui-même les nouvelles versions dans sa boîte de
   réception.

## Installer

Télécharge `OutilSauvegardeRR.zip` dans la dernière version (onglet **Releases**), décompresse-le,
puis lis `LIS_MOI.txt` : tout y est expliqué pas à pas.

## Ce que l'outil contient, et ce qu'il ne contient pas

Seulement notre propre travail : le code de l'outil, nos retouches du jeu et le serveur hors
ligne. **Aucun fichier du jeu** : chaque joueur fournit son propre exemplaire officiel, et
l'outil le modifie sur son ordinateur. Rien n'est envoyé nulle part, à part la question « y
a-t-il une nouvelle version ? » posée à GitHub.
