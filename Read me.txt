RANGER RUMBLE HORS LIGNE - Ratchet & Clank: Ranger Rumble
=========================================================

À QUOI ÇA SERT
--------------
Les serveurs du jeu ferment le 1er mai 2027 : le jeu ne marchera plus et toutes les
parties seront effacées. Cet outil fait quatre choses :

1. COPIER LA SAUVEGARDE (avant le 1er mai 2027)
   Garde une copie de la sauvegarde et des données du jeu que les serveurs officiels
   envoient au démarrage (sur iPhone). Sur Android, rien à copier : la sauvegarde ne
   peut pas être copiée (voir la partie Android).

2. INSTALLER LE JEU
   Fabrique une version du jeu qui marche sans serveur, pour un téléphone ou une
   tablette Android, avec la sauvegarde dedans. Le jeu officiel en version 1.10.4 est
   à fournir : l'outil ne contient pas le jeu, il modifie celui qui lui est donné.
   L'outil apporte tout le reste : les 7 héros jamais sortis, l'artbook, des costumes,
   les cartes de Rivet, Juycee et Wendy, les images de Mme Zurkon et l'écran de collecte
   de son événement.

3. ÉDITER UNE SAUVEGARDE
   Tout se change dans une sauvegarde : héros débloqués et leur niveau, armes, costumes,
   médailles, monnaies, parties jouées, gagnées, perdues... Une partie vierge est aussi
   possible. La sauvegarde vient d'un fichier, d'une copie, ou directement du téléphone
   par le câble, et y retourne de la même façon.

4. MISES À JOUR
   Installe les nouvelles versions de l'outil, puis met à jour le jeu hors ligne du
   téléphone par le câble, sans perdre la progression.

Tout reste sur l'ordinateur. L'outil n'envoie rien nulle part : il demande seulement à
GitHub s'il existe une nouvelle version (le jeu hors ligne aussi, une fois par jour).


CE QU'IL FAUT
-------------
- Un ordinateur Windows ou Mac.
- Rien d'autre à installer : sans Python sur l'ordinateur, l'outil télécharge le sien
  la première fois (25 à 75 Mo, sans mot de passe).
  Si Windows bloque ce téléchargement : installer Python depuis python.org (cocher
  « Add python.exe to PATH »), puis relancer.
- Internet la première fois : l'outil télécharge ses composants (mitmproxy, msgpack, segno,
  qui dessine le QR code, et UnityPy, numpy et Pillow, qui retouchent les images et les
  modèles du jeu). Compter quelques minutes.
- Pour le jeu : le fichier du jeu officiel en version 1.10.4, en .xapk (APKPure),
  .apkm (APKMirror) ou .apk avec tout le jeu dedans. Les modèles des 7 héros jamais
  sortis sont fournis avec l'outil.
  Il faut aussi environ 5 Go libres sur l'ordinateur, et un téléphone ou une
  tablette Android 64 bits (Android 7.1 ou plus récent).


LANCER L'OUTIL
--------------
- Windows : la 1re fois, double-cliquer sur « Lancer (Windows).bat ». Il met le raccourci
  « Ranger Rumble hors ligne » sur le Bureau : ensuite, l'outil se lance avec lui.
  Si Windows demande l'autorisation du pare-feu pour Python : Autoriser. Si l'iPhone
  reste sur une page blanche, l'outil propose de régler le pare-feu : accepter.
- Mac : double-cliquer sur « Ranger Rumble hors ligne ».
  Si le Mac refuse de l'ouvrir : Réglages Système > Confidentialité et sécurité >
  Ouvrir quand même.
  Si le Mac demande d'accepter les connexions entrantes pour Python : Autoriser.

La première fois, l'installation prend quelques minutes dans une fenêtre de texte : la
laisser ouverte. Ensuite l'outil s'ouvre.

Sur l'accueil, choisir où est le jeu : « iPhone ou iPad » ou « Android », puis suivre les
étapes 1 et 2. Dans ce guide, seule la partie qui correspond à ce choix est utile, puis
« Installer le jeu sur Android ».


=====================================================================
JEU SUR IPHONE OU IPAD
=====================================================================

Il faut l'iPhone ou l'iPad avec le jeu, sur le même Wi-Fi que l'ordinateur, et les
serveurs encore ouverts.

ÉTAPE 1 : COPIER LA SAUVEGARDE
------------------------------
Rien à régler à la main : le profil RatchetRR ajoute un DNS (comme un VPN) pour les
seuls serveurs du jeu. Le reste de l'iPhone ne passe pas par l'ordinateur.

a. Cliquer sur « Démarrer » : un QR code s'affiche.

b. Sur l'iPhone, viser le QR code avec l'appareil photo et toucher le lien qui apparaît
   (ou ouvrir Safari à l'adresse écrite sous le QR code).
   - Toucher « Télécharger le profil RatchetRR », puis « Autoriser ».
   - Ouvrir Réglages : en haut, toucher « Profil téléchargé » (ou Général > VPN et gestion
     de l'appareil > RatchetRR). Installer > code de l'iPhone > Installer.
   - Revenir dans Général > Informations (pas VPN). Tout en bas de cette page :
     « Réglages des certificats ». Cette ligne n'apparaît qu'après l'étape précédente.
     Activer « RatchetRR » > Continuer.
   - Si l'iPhone a encore un profil « mitmproxy » (installé avec une ancienne version
     de cet outil), le supprimer : il ne sert plus.

c. Ouvrir Ranger Rumble et attendre l'écran d'accueil. C'est tout. Le point à côté de
   « Démarrer » devient orange, puis vert : « C'EST FAIT : SAUVEGARDE ET DONNÉES
   COPIÉES ! » (environ 30 secondes après « Sauvegarde copiée »). Attendre le vert.

d. Après :
   - Réglages > Général > VPN et gestion de l'appareil > RatchetRR > Supprimer le profil.
   - La copie s'arrête toute seule une fois le point vert.
   - Si le proxy a été réglé à la main : Réglages > Wi-Fi > (i) > Configurer le
     proxy > Désactivé.

Le profil doit être supprimé : tant qu'il est là, le jeu officiel ne se connecte plus
quand l'outil est arrêté.

Une copie peut être refaite à tout moment, par exemple après avoir encore joué : seule
la dernière est à jour. Faire la dernière juste avant le 1er mai 2027.

ÉTAPE 2 : FABRIQUER L'APK
-------------------------
a. « Jeu officiel 1.10.4 » : cliquer sur « Choisir... » et prendre le fichier .xapk,
   .apkm ou .apk du jeu. L'outil vérifie que c'est bien la version 1.10.4.
b. « Sauvegarde exportée » : la progression. Après une copie iPhone (étape 1), elle
   se remplit toute seule. Sinon, « Dossier... » : choisir le dossier des sauvegardes
   (copies iPhone ou fichiers), puis la sauvegarde dans la liste.
c. Ou cocher « Nouvelle partie » pour commencer de zéro.
d. « APK à créer » : où mettre le fichier fabriqué.
e. Cliquer sur « 1. Fabriquer l'APK ». Cela prend de une à quelques minutes. À la fin,
   l'APK fait environ 1,3 Go.

ÉTAPE 3 : JOUER
---------------
La version hors ligne se joue sur un téléphone ou une tablette Android : il n'y en a
pas pour iPhone ou iPad. Voir « Installer le jeu sur Android » plus bas.


=====================================================================
JEU SUR ANDROID
=====================================================================

La sauvegarde n'est pas sur le téléphone : seuls les serveurs officiels la gardent, et
le jeu la télécharge à chaque lancement. Sur Android, aucune autre appli n'a le droit
de lire ce que le jeu officiel reçoit ou garde (sans téléphone rooté), et le serveur
officiel refuse toute version modifiée du jeu. La sauvegarde Android ne peut donc pas
être copiée : le jeu hors ligne part d'une nouvelle partie ou d'une sauvegarde exportée.

Il faut un câble USB qui transmet les données.

AVANT DE COMMENCER : le débogage USB (une seule fois)
- Paramètres > À propos du téléphone : toucher 7 fois de suite « Numéro de build »
  (sur Samsung : À propos du téléphone > Informations sur le logiciel). Le téléphone
  dit « Vous êtes maintenant développeur ».
- Paramètres > Système (ou directement Paramètres) > Options pour les développeurs :
  activer « Débogage USB ».
- Brancher le téléphone à l'ordinateur. Sur le téléphone, glisser du haut de l'écran,
  toucher la notification USB et choisir « Transfert de fichiers ».
- Toucher « Autoriser » quand le téléphone demande « Autoriser le débogage USB ? ». La
  première fois, l'outil propose aussi de télécharger les outils Android de Google (10 Mo).

FABRIQUER L'APK
Rien à copier sur Android : l'outil apporte les données du jeu. Dans « Installer le jeu »,
choisir une sauvegarde exportée, ou cocher « Nouvelle partie ». Une nouvelle partie
commence comme un nouveau compte : le jeu demande l'âge et les choix de confidentialité,
puis lance son didacticiel.

Garder aussi le fichier du jeu officiel 1.10.4 (.xapk, .apkm ou .apk) : il ne sera
peut-être plus téléchargeable après la fermeture des serveurs. Il sert aussi
aux mises à jour.


=====================================================================
INSTALLER LE JEU SUR ANDROID
=====================================================================

- Le plus simple : brancher l'appareil (débogage USB activé, voir la partie Android) et
  cliquer sur « 2. Installer sur le téléphone ».
- Ou copier l'APK sur le téléphone ou la tablette (câble USB, carte SD, cloud...) et
  l'ouvrir depuis l'application Fichiers. Android demande d'autoriser l'installation
  d'applications de cette source : accepter. Si Play Protect affiche un avertissement,
  choisir d'installer quand même : il prévient parce que l'application n'est pas signée
  par Sony.
- Si le jeu officiel est installé sur cet appareil, le désinstaller d'abord (seulement
  quand il ne sert plus) : l'APK porte le même nom d'application. Après ça, cet appareil
  ne joue plus en ligne.
- Le jeu démarre directement sur la sauvegarde, sans connexion (le premier démarrage
  prend quelques minutes). La difficulté se règle dans les réglages du jeu, onglet Général,
  ligne « Difficulté ».

Garder la progression hors ligne : elle vit dans le jeu, sur l'appareil. Si le jeu est
désinstallé, si l'appareil change ou casse, elle est perdue. De temps en temps, brancher
l'appareil, puis dans « Éditer une sauvegarde » : « Le téléphone (câble) », puis
« Enregistrer sous... ». Mettre le fichier à l'abri. « Envoyer au téléphone » la remet.

Mettre à jour plus tard : un nouvel APK fabriqué sur le MÊME ordinateur s'installe
par-dessus l'ancien, et la progression hors ligne est gardée. L'APK est signé avec une
clé créée sur l'ordinateur (dossier « .sauvegarde-rr » du dossier personnel, fichier
cle_apk.p12). Il faut la garder : avec une autre clé, l'ancien APK doit être désinstallé.
Exporter alors la progression avant, puis l'importer dans le nouveau.


JOUER À PLUSIEURS
-----------------
Le jeu fabriqué ici joue en groupe avec les autres joueurs dont le jeu vient aussi de cette
version de l'outil. Avec un jeu fait par une version plus ancienne, ils ne se voient pas :
il faut le refaire.
- Sur le même Wi-Fi : les joueurs apparaissent tout seuls dans « Amis ». Les inviter avec
  « Faire équipe » (TEAM UP). Un Wi-Fi « invité » empêche souvent les téléphones de se voir.
- À distance : le chef du groupe touche « Faire équipe », puis « Créer » (CREATE), et donne
  le code de 8 caractères. Les autres l'entrent avec « Rejoindre » (JOIN). 0 ou O, 1 ou I :
  peu importe, le code marche des deux façons.
- Quand tout le monde est « prêt », le chef appuie sur « Jouer » (PLAY) : tout le groupe
  entre dans le même combat. C'est le téléphone du chef qui héberge la partie.
- À distance, le combat passe par des relais internet publics, chiffrés avec le code du
  groupe. Il peut être un peu moins réactif qu'en Wi-Fi.
- 3 joueurs au plus par groupe. Seul, on joue toujours hors ligne, sans attendre.
- Tous les modes se jouent en groupe (Bolt Rush, Bolt Rush Coop et Battle Royale 16
  compris), sauf Mob Rush (les vagues de monstres), qui se joue seul. Le défi de Rivet et
  l'arme au hasard aussi se jouent en groupe.


ÉDITER UNE SAUVEGARDE
---------------------
1. Ouvrir une sauvegarde, avec un des boutons du haut :
   - « Un fichier... » : un save.msgpack, ou une sauvegarde enregistrée avant ;
   - « Une copie... » : le dossier d'une copie faite avec « Copier ma sauvegarde » ;
   - « Le téléphone (câble) » : la sauvegarde actuelle du jeu hors ligne du téléphone
     branché (débogage USB activé, voir la partie Android). L'outil en garde une copie
     dans le dossier Sauvegardes ;
   - « Partie vierge » : une nouvelle partie, comme un nouveau compte.
2. Faire les changements. Double-cliquer sur une valeur pour la changer, ou sur une case
   « Débloqué » pour la cocher ou la décocher :
   - Profil et statistiques : pseudo, monnaies, parties jouées, gagnées, perdues,
     séries de victoires, record de médailles...
   - Héros : débloqués ou non, niveau (1 à 10, comme dans le jeu), talents, lorbes,
     médailles de chaque héros, série de victoires ;
   - Armes et gadgets : débloqués ou non, niveau, améliorations, plans ;
   - Costumes et Modes de jeu ;
   - Tout (avancé) : toute la sauvegarde, champ par champ, avec les noms du code du jeu.
     À manier avec précaution.
3. Puis :
   - « Envoyer au téléphone » : le jeu du téléphone se ferme et redémarre avec cette
     sauvegarde. L'ancienne est rangée dans l'historique du jeu ;
   - « Enregistrer sous... » : un fichier, à garder à l'abri ;
   - « Utiliser pour fabriquer l'APK » : le jeu fabriqué partira de cette sauvegarde.
Garder une copie de la sauvegarde avant de gros changements.


MISES À JOUR
------------
- Il y a deux numéros de version : celui de l'OUTIL (ce logiciel) et celui du JEU (l'APK du
  téléphone). Le jeu ne change pas à chaque version de l'outil : seulement quand le jeu
  lui-même a des nouveautés.
- À chaque ouverture, l'outil regarde si une nouvelle version de l'outil est sortie. Si oui,
  le titre de la fenêtre le dit : « Mises à jour », puis « Mettre à jour l'outil ». Les
  copies ne bougent pas. Relancer l'outil ensuite. La page dit aussi si le jeu change avec
  elle.
- Le jeu hors ligne du téléphone prévient dans sa boîte de réception (Inbox) quand une
  nouvelle version du JEU est sortie.
- Pour mettre à jour le jeu du téléphone : le brancher, puis « Mettre à jour le jeu du
  téléphone ». L'outil refabrique l'APK avec les fichiers de « Installer le jeu » et la
  sauvegarde actuelle du téléphone, et l'installe par-dessus : la progression est gardée.
- Si le jeu du téléphone a été fabriqué sur un autre ordinateur, il ne peut pas être
  installé par-dessus : l'outil propose alors de le désinstaller et de le réinstaller, en
  repartant de la sauvegarde. Les réglages du jeu reviennent à leurs valeurs de départ.


GALERIE D'ARTWORKS
------------------
- Dans le jeu : menu (les 3 traits en haut à droite) > ARTBOOK. L'artbook du jeu (plus de
  600 images rangées par thème) est là, et les images personnelles au chapitre « Mes
  images ». Les images s'affichent en grille ; toucher une image pour la voir en grand
  (pincer ou toucher deux fois pour zoomer, glisser pour passer à la suivante, Retour pour
  revenir au jeu).
- Pour y mettre des images : dans « Installer le jeu », « Images de la galerie » (un
  dossier d'images png ou jpg) avant de fabriquer l'APK. Ou plus tard, les copier par le
  câble dans le dossier Android/data/com.playstation.rattlesnake/files/artworks du
  téléphone (il apparaît après la première ouverture de la galerie).


OÙ SONT LES COPIES ?
--------------------
Dans le dossier « Sauvegardes », à côté de l'outil (bouton « Ouvrir le dossier des
copies »). Chaque copie a son dossier, nommé avec l'identifiant du compte et la date.
Il contient :
- save.msgpack : la sauvegarde exacte envoyée par les serveurs officiels ;
- sauvegarde_lisible.json : la même chose en texte lisible ;
- events.msgpack : l'état des événements du compte ;
- donnees_serveur : les données du jeu qu'il faut pour fabriquer l'APK ;
- INFO.txt : le compte, la date et le nombre de parties.
Garder ce dossier en lieu sûr (clé USB, cloud...).


SÉCURITÉ
--------
- L'outil n'envoie rien nulle part, à part la question « y a-t-il une nouvelle version ? »
  posée à GitHub (sans aucune donnée personnelle). Pendant la copie, le jeu parle à ses
  serveurs comme d'habitude, l'outil garde seulement une copie de ce qu'il reçoit. Une
  seule exception : si le jeu n'a pas téléchargé un fichier de configuration public,
  l'outil le télécharge lui-même à la même adresse, sans aucune donnée du compte.
- Aucun mot de passe ni jeton de connexion n'est enregistré : chaque fichier est vérifié
  avant d'être écrit.
- Seules les connexions du jeu sont lues. Les autres applis passent sans être lues.
- Le certificat et la clé de l'APK sont créés sur l'ordinateur, dans le dossier
  « .sauvegarde-rr » du dossier personnel. Ne jamais partager ce dossier, et supprimer
  le profil de l'iPhone après la copie.
- Ne pas partager les copies non plus : elles contiennent le compte.


SI ÇA NE MARCHE PAS
-------------------
- Le bouton « Démarrer » est grisé : choisir « iPhone ou iPad » sur l'accueil.
- La page http://...:8090 ne s'ouvre pas sur l'iPhone : les deux ne se voient pas.
  Vérifier qu'ils sont sur le même Wi-Fi (un Wi-Fi « invité » empêche souvent les
  appareils de se voir) et le pare-feu de l'ordinateur.
- La fenêtre n'affiche jamais « L'iPhone utilise le profil RatchetRR » : l'adresse de
  l'ordinateur a changé depuis l'installation du profil. Supprimer le profil, puis
  recharger la page sur l'iPhone et le réinstaller. En dernier recours, la fenêtre donne
  le proxy à régler à la main (Serveur et Port).
- « L'iPhone refuse le certificat » : il manque l'activation de RatchetRR dans Réglages
  des certificats (étape 1.b).
- « Le jeu refuse le certificat » : il manque l'activation de RatchetRR dans Réglages
  des certificats (étape 1.b). Ensuite, fermer complètement le jeu et le rouvrir.
- Le jeu affiche une erreur de connexion : le fermer complètement et le rouvrir.
- « La sauvegarde reçue est vide » : le jeu a ouvert un nouveau compte vide au lieu du
  bon. Fermer le jeu et le rouvrir, ou reconnecter le compte dans le jeu.
- « Données du serveur incomplètes » : fermer complètement le jeu, le rouvrir et attendre
  l'écran d'accueil, sans arrêter la copie.
- Une copie est marquée « ancienne copie, sans les données du serveur » : elle a été
  faite avec une ancienne version de l'outil, qui ne gardait que la sauvegarde. Refaire
  une copie (étape 1).
- « Ce fichier n'est pas la version 1.10.4 attendue du jeu » : il faut exactement la
  version 1.10.4 (pas 1.10.3 ni une autre).
- La fabrication échoue faute de place : libérer environ 5 Go sur le disque où l'APK
  est créé.
