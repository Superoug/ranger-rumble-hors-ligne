RANGER RUMBLE OFFLINE - Ratchet & Clank: Ranger Rumble
=======================================================

Keep playing after the game's servers shut down on May 1, 2027.


WHAT YOU NEED
-------------
- A Windows or Mac computer. Internet the first time (a few minutes of installing).
  If Python is missing, the tool downloads its own (25 to 75 MB). If Windows blocks it:
  install Python from python.org (tick "Add python.exe to PATH"), then start again.
- The official game 1.10.4: .xapk (APKPure), .apkm (APKMirror) or a complete .apk.
  Keep this file: it may not be downloadable after the servers shut down.
- 5 GB free on the computer.
- A 64-bit Android phone or tablet (Android 7.1 or newer) and a USB data cable.
- To copy a save: the iPhone or iPad with the game, on the same Wi-Fi as the computer,
  before May 1, 2027.


START THE TOOL
--------------
- Windows: the first time, double-click "Lancer (Windows).bat". Then use the
  "Launcher Ratchet Ranger Rumble" shortcut on the Desktop.
- Mac: open "Launcher Ratchet Ranger Rumble". If the Mac refuses: System Settings >
  Privacy & Security > Open Anyway. On macOS 12 or older, open "Lancer (Mac).command"
  instead: it starts the classic window.
- If the computer asks to allow incoming connections for Python: Allow.

In the launcher, choose "Android". It has four tools.


1. COPY THE IPHONE SAVE (iPhone or iPad only)
---------------------------------------------
1. Put the iPhone on the same Wi-Fi as this computer.
2. Click "Start". Scan the QR code with the camera, then download the RatchetRR profile.
3. Settings > General > at the very bottom, "VPN & Device Management" > RatchetRR:
   Install.
4. Settings > General > About: at the very bottom, "Certificate Trust Settings" > turn
   on RatchetRR.
5. Open Ranger Rumble and wait for the home screen.

When the launcher says the save is copied, remove the profile: Settings > General >
VPN & Device Management > RatchetRR > Remove Profile. Otherwise the official game no
longer connects.

Copy again whenever you like: the latest copy counts. Make a last one just before
May 1, 2027.

On Android, the save cannot be copied: the official server keeps it and refuses any
modified game. Start from an iPhone copy, an exported save or a new game.


2. BUILD AND INSTALL (Android)
------------------------------
1. Turn on USB debugging once. The "i" next to "No phone plugged in" shows how:
   "Build number" 7 times, then Developer options > USB debugging.
2. Plug in the phone. On the phone: USB notification > "File transfer", then "Allow".
3. Choose the official game 1.10.4, a save (or "New game") and the APK to create.
4. Click "Build the APK", then "Install on the phone".

- If the official game is on the phone, uninstall it first. That phone then no longer
  plays online.
- The game starts by itself, offline. The first start takes a few minutes.
- Difficulty: in the game's settings, General tab.
- Without a cable: copy the APK to the phone and open it from Files. Accept the
  install. If Play Protect warns, install anyway (the game is not signed by Sony).


3. EDIT A SAVE
--------------
1. Open a save: "The phone", "A file…", "A copy…" or "Blank game".
2. Change heroes, weapons, skins, modes, currencies and stats. The "Everything" tab
   shows the whole save: handle with care.
3. Then "Send to the phone", "Save as…" or "Use for the APK".

The offline progress lives on the phone: deleting the game deletes it. Now and then,
open "The phone", then "Save as…", and keep the file somewhere safe.


4. UPDATES
----------
- The launcher checks for new versions. Install them from the Updates page.
- The game announces a new game version in its Inbox. Plug in the phone and click
  "Update the phone": progress is kept.
- The game is signed with a key made on this computer (".sauvegarde-rr" folder in the
  home folder). Keep this folder. A game built on another computer must be reinstalled:
  the launcher offers it, progress is kept, the game's settings go back to default.


PLAYING TOGETHER
----------------
- Everyone needs a game built by the same version of the tool.
- Same Wi-Fi: friends show up in "Friends". Invite them with "TEAM UP". Guest Wi-Fi
  networks often block this.
- Remotely: the leader taps "TEAM UP" > "CREATE" and shares the 8-character code. The
  others enter it with "JOIN".
- Up to 3 players. Every mode except Mob Rush.


ARTBOOK
-------
In the game: menu (top right) > ARTBOOK. To add your own pictures ("My images"), choose
"Gallery images" before building, or copy them by cable into the phone's folder
Android/data/com.playstation.rattlesnake/files/artworks.


YOUR FILES
----------
- "Sauvegardes" folder, next to the tool ("Copies folder" button): one folder per copy
  (save.msgpack, a readable save, the game data, INFO.txt). Keep it safe, never share
  it: it holds your account.
- ".sauvegarde-rr" folder, in the home folder: settings, the game's signing key, the
  iPhone certificate. Never share it.


IF IT DOES NOT WORK
-------------------
- The iPhone cannot open the page: same Wi-Fi? Guest Wi-Fi often blocks devices. Check
  the computer's firewall.
- "The game refuses the certificate": redo step 4, then close the game completely and
  reopen it.
- The launcher never sees the profile: remove it and install it again from the QR code.
- "The save received is empty": close the game and reopen it, or reconnect the account
  in the game.
- No phone found: USB notification > "File transfer", USB debugging on, "Allow" on the
  phone.
- "Not the expected 1.10.4 version": exactly 1.10.4 is needed.
- Not enough space: free 5 GB on the disk where the APK is created.
